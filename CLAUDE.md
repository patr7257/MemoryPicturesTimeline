# CLAUDE.md

Family photo memory timeline at `https://memories.patrickrobel.dk`. Private:
family-only login, photos never publicly reachable.

## Facts a session needs

- **Deploy**: Dokploy app `memories` (applicationId `aO-snDweznAl5O7zsPhHc`,
  project `memories`) on the Hetzner VPS (`ssh todolist-vps`,
  `178.104.231.9`). Docker build from `Dockerfile`, port 3000, domain via
  Traefik + Lets Encrypt. **Push to `main` = production deploy** (GitHub
  webhook; watch paths cover src/public/package/Dockerfile/drizzle, and note
  dotfiles do NOT match the globs). Dokploy API: token at `~\.dokploy\token`,
  header `x-api-key`, base `https://deploy.patrickrobel.dk/api`
  (tRPC-style, e.g. `application.deploy`, `deployment.all`). Panel:
  `https://deploy.patrickrobel.dk`.
- **DB**: Neon project `family-memories` (`wild-heart-81141768`, Frankfurt),
  reachable via `DATABASE_URL` in `.env`. Drizzle migrations in `drizzle/`;
  `pnpm db:generate` + `pnpm db:migrate`. Local dev and prod share this one
  database. Neon is managed through the Vercel org ("przrm's projects"), so
  new projects are created with `vercel integration add neon ...`, NOT the
  Neon console/CLI.
- **Auth**: Better Auth 1.6 (`src/lib/auth.ts`), passkey plugin from
  `@better-auth/passkey`, magic link via ZeptoMail (`src/lib/email.ts`).
  NO passwords, ever. Allowlist in `FAMILY_EMAILS` env (comma-separated);
  prod rpID is `patrickrobel.dk`. `src/db/auth-schema.ts` is generated by
  `pnpm auth:generate`; never hand-edit.
- **Photos**: R2 private bucket (creds in env, `src/lib/r2.ts`). Upload =
  presigned PUT from the browser, then `/api/upload/finalize` (sharp 400/1200
  WebP + blurhash + BigDataCloud reverse geocode, idempotent via unique
  `r2_key_original`). Serving = authenticated `/api/img/[id]/[size]` proxy,
  `next/image` is intentionally unused (`images.unoptimized`).
- **Scrapbook rule**: every rotation/offset derives from stable ids via
  `src/lib/scrapbook.ts`. Math.random() in render paths causes hydration
  mismatches; never introduce it.
- **typedRoutes**: after adding a route, run `pnpm build` (or dev) once to
  regenerate route types, else `pnpm check-types` fails on Link hrefs.

## Commands

- `pnpm dev` / `pnpm build` / `pnpm check-types` / `pnpm test`
- Env setup: `.\scripts\setup-env.ps1` (prompts only for empty keys)
- Prod env push: `.\scripts\push-dokploy-env.ps1`

## Conventions

- Mirrors PatrickRobelWeb conventions (Tailwind v4 CSS-variable theme in
  `src/app/globals.css`, shadcn base-lyra, `@/*` alias, lazy memoized db in
  `src/db/index.ts`).
- Patrick-run commands are ALWAYS committed scripts under `scripts/` (.ps1 +
  .sh), never inline one-liners.
- Single warm light theme; no dark mode in v1.
